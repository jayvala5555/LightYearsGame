## 🎮 About

**LightYearsGame** is a game being developed completely from scratch in **C++**.

This repository serves both as:

- A game development project
- A learning journey
- A development log documenting progress, challenges, and solutions

The goal is to design, build, and polish a complete game while gaining a deeper understanding of:

- Game architecture
- Rendering systems
- Physics and collision handling
- Input management
- Asset pipelines
- Performance optimization
- Software engineering practices in C++

---

## 🎯 Project Goals

- Build a game from the ground up
- Write clean and maintainable C++ code
- Learn game engine concepts
- Track milestones and technical decisions
- Create a playable and polished final product
